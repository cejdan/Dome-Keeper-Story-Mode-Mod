# How deep is a Story Mode map, and on which layer does each mineral tier and gate start?

Type: grilling (HITL)
Status: open
Blocked by: 09

## Question

Set the shape of the descent: total depth, number of layers, the layer where each mineral first appears and peaks, and the layers where metal gates sit. Base-game archetypes default to 40 tiles deep; nine mineral tiers plus gates likely need more.

The brief's example: layer 1 all bronze; layer 2 90% bronze, 10% iron; layer 3 50% bronze, 50% iron, 5% gold.
