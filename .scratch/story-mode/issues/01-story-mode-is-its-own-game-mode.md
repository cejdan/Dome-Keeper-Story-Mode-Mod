# Story Mode is its own game mode

Type: grilling (HITL)
Status: resolved
Blocked by: none

## Question

Should Story Mode be a separate game mode in the loadout screen, or change how the regular mode plays?

## Answer

Separate game mode, registered with `Data.registerGameMode`. Vanilla modes stay untouched, which also allows side-by-side comparison with the base game. Decided by the user on 2026-11-10.
